# ApplyTrack — Learning Log

The purpose of this project is not only to produce an application. It is to build independent engineering ability.

## Rule

Whenever you learn something that previously confused you, record it briefly.

Do not write tutorial-style essays. Record the mental model you will want six months later.

## Entry template

```text
Date:
Phase:
Topic:

What I thought before:

What is actually happening:

What caused my confusion:

Small example:

What I can now explain:

What is still unclear:
```
